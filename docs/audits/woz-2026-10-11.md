#### WOZ-001 Polling Wine : écriture inconditionnelle d'un `@Published`
- **Fichier** : `Sources/WoWSiliconSwift/ViewModels/MainDashboardViewModel.swift:315` (déclaration `:26`)
- **Problème** : `wineProcessCount = processCount` à chaque tour de `monitorWineProcesses()`. Avec `@Published`, toute affectation émet `objectWillChange`, même à valeur égale : `MainDashboardView` (et `OptionsView` si la feuille est ouverte) réévaluent leur `body` à chaque tick.
- **Sous-règle** : axe 4.3 (sauter l'invalidation quand la valeur ne change pas).
- **Correctif 5 min** : `if wineProcessCount != processCount { wineProcessCount = processCount }`.
- **Référence** : choix maison (aucune règle HIG ; corpus axe 4).

## Forces (hits gardés, comptés à part)

529 hits gardés. Les plus parlants :

- **Découpage de l'écran racine** : `MainDashboardView.swift` compose `HeaderView`, `MainContentView`, `BottomBarView`, `PathRow`, `PatchRow`, `StatusLabel`, `LogoView`… qui reçoivent des valeurs étroites (axes 1.1, 4.5). C'est la forme à reproduire dans Options.
- **`@MainActor` sur 6/6 ViewModels** (axe 4.2) et `private(set)` sur les `@Published` exposés.
- **Lignes de `List` unaires** : `AddonManagerView.swift:136` et `ModManagerView.swift:55` enveloppent chaque ligne dans un `VStack` (axe 12.1).
- **Identité** : `id: \.self` uniquement sur des enums `CaseIterable` ou des entiers fixes ; `.enumerated()` avec `id: \.element.id` (`MainDashboardView.swift:807`, wrapper `Array` requis : la conformance `Collection` d'`enumerated()` n'est pas disponible sur la cible macOS 14).
- **Environnement** : `@Entry var isGameRunning = false` (défaut stable, 13.5/13.7) ; les 5 lectures `@Environment` sont toutes utilisées ; l'effet de bord `onChange` est déjà isolé dans `ECOAnimationModifier` (4.9).
- **Init de vues** : `RealmlistEditorView.swift:13` et `:315` initialisent `@State` par `State(initialValue:)` sans valeur de déclaration — la forme correcte vis-à-vis de 14.1/14.2 ; les 394 accès disque/JSON sont tous dans les services, stores et tests (axe 11).
- **Aucun `.if`**, modificateurs conditionnels par ternaire (`PlayButtonStyle.swift:29-31`).
